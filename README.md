# android find with Orientation

純前端 Kotlin 原生 Android 客戶端。沒有伺服器、沒有帳號。兩台都裝了這個 App、並授予藍牙與測距權限後，尋找中的裝置會在 **10 米**範圍內，即時畫出其他客戶端的方向。

公開倉庫：<https://github.com/wusui1325-dotcom/android-find-with-orientation>

## 它做什麼

- 只用藍牙低功耗廣播一個私有服務 UUID，所以雷達上只會出現裝了本客戶端的裝置。
- 尋找端連接對端 GATT，交換名稱與 UWB 測距參數。
- 兩台都有 UWB 時，用 AndroidX `core-uwb` 做雙向測距。距離是米，方位角是相對手機頂端的角度，範圍約 -90° 到 90°。
- 沒有 UWB 時，用 RSSI 估算距離；使用者緩慢轉身後，取訊號最強的朝向當作大約方向。
- 估計或測距超過 10 米的裝置不畫上雷達。

## 硬體限制

實時角度不是每支手機都做得到。

| 能力 | 條件 |
| --- | --- |
| 實時方位角與距離 | 雙方都有 UWB，例如 Pixel 6 Pro 及之後的 Pro、部分 Galaxy S21+ 以後機型，且系統已開 UWB |
| 大約方向 | 無 UWB 時要緩慢轉一圈，讓程式對到訊號峰值 |
| 只顯示距離環 | 還沒轉夠，或角度尚未鎖定 |

單一天線藍牙不能像 UWB 那樣直接給出到達角。這不是雲端定位，室內 GPS 也測不準 10 米。

## 權限

藍牙掃描、廣播、連接、精確位置、UWB 測距、通知。精確位置是因為部分系統在沒有位置權限時不回傳藍牙掃描結果。資料只留在兩台手機之間，不上網。

## 使用

1. 用 Android Studio 開啟本目錄，等 Gradle 同步。
2. `minSdk` 31，建議真機兩台。
3. 兩邊都按「開始」，並打開「可被發現」。
4. 要看別人的，打開「尋找其他裝置」。手機頂端對準前方。
5. 琥珀色點是 UWB 角度，藍色點是旋轉估計。

## 常駐被發現

打開「常駐被發現」再按「開始」後，前景服務會一直廣播。開機或更新 App 後會自行恢復。常駐時只廣播、不掃描，等別的客戶端來找。

這不是強制停止後也能活。Android 不允許被強制停止的 App 自行起來。部分廠商還會殺前景服務，所以要再按「允許背景運行」。通知必須留著。

## 後備定位

優先順序是 UWB、融合定位、旋轉估計。

融合定位用系統 `LocationManager` 的 GPS 與網絡位置，經藍牙交給對端，再算方位角和距離。這是每支手機都有的方案，不依賴 Google Play。室外、雙方誤差小於 30 米時可用。10 米內的衛星誤差常常大於兩機距離，所以它標成綠色，並顯示誤差。室內不要指望它。

藍牙通道探測和 Wi-Fi RTT 更準，但要雙方硬體支援，普及度還不如 GPS，所以沒有當成預設後備。

## 建置

可以拉下來直接編。需要 Android Studio、JDK 17、Android SDK 36。第一次同步會下載 Gradle 8.11.1。

```bash
git clone https://github.com/wusui1325-dotcom/android-find-with-orientation.git
cd android-find-with-orientation
./gradlew :app:assembleDebug
```
